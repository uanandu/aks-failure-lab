# AKS Failure Lab

**Break systems. Build judgment.**

Learn to troubleshoot Azure Kubernetes Service (AKS) by breaking a real distributed app on purpose, then diagnosing and fixing it.

**https://uanandu.github.io/aks-failure-lab/**

## What's inside

- 17 hands-on labs, from Pod failures to AKS platform investigations
- Hints, solution guidance, and reflection prompts for each lab
- Progress dashboard with milestones and three learning paces
- A single HTML file with no install, account, or tracking

Progress is saved in your own browser only.

## What you need

- An AKS cluster in a non-production subscription
- Azure CLI, kubectl, and Git

The labs use Docker's [Example Voting App](https://github.com/dockersamples/example-voting-app).

## Disclaimer

An independent learning project, not affiliated with Microsoft or Docker. Run fault-injection labs only in non-production environments.
